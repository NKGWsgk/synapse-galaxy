※ 画面の名称は、GA4 の標準的な画面に基づく。開発はGA4の管理画面を直接は開いていないので、名称が違ったら読み替えること。

## いま取れているもの

- 取れている: ページビュー（`page_view`）と、GA4の「拡張計測機能」の標準イベント（スクロール、外部リンクのクリック、サイト内検索など。管理 > データストリーム で設定を確認できる）。
- **取れていない: 投稿完了（シナプス作成）、Xシェアのクリック。** コードにカスタムイベントはない（`sendGAEvent` / `gtag` の呼び出しなし）。追加する場合の規模は、下の「追加するなら」を参照。
- Search Console は 2026-11-15 に登録・sitemap（48URL）送信済み。表示回数・クリック・インデックスの数字は、登録の翌日以降（目安は数日〜数週間）にならないと出ない。

## 毎週見るもの（GA4）

1. **ページ別の訪問数**
   - レポート > エンゲージメント > ページとスクリーン。
   - 表の上の検索ボックスに `/work/`（作品ページ）、`/s/`（シナプス共有ページ）、`/user/`（ユーザーページ）、`/news/like-award` を入れて絞る。見る列は「表示回数」と「アクティブユーザー」。
   - 期間は右上の日付で変える。まず「過去7日間」と「前の期間と比較」。
2. **流入元**
   - レポート > 集客 > トラフィック獲得。表の左上のプルダウンで、ディメンションを「セッションのデフォルト チャネル グループ」から「セッションのソース / メディア」に切り替える。
   - 目安: 検索 = `google / organic`、noteからの流入 = `note.com / referral`（UTMを付ければ `note / article`）、X = `t.co / referral`、直接 = `(direct) / (none)`。
3. **UTM別**
   - noteの記事からサイトへ貼るリンクには、`?utm_source=note&utm_medium=article&utm_campaign=<記事名>` を付ける。「セッションのソース / メディア」と、ディメンション「セッションのキャンペーン」で、記事別に見られる。
   - Xの紹介は `utm_source=x&utm_medium=social&utm_campaign=<投稿名>`。
4. **自由に切り分ける:** 探索 > 空白 > 自由形式。行にディメンション「ページパスとスクリーンクラス」、値に「表示回数」「アクティブユーザー」を入れ、フィルタで `/work/` などを指定。

### 注意
- 運営者自身のアクセスが混ざる。管理 > データストリーム > タグ設定 > 内部トラフィックの定義、で自分のIPを除外できる（IPが変わる環境では限界がある）。
- 反映には、通常、数時間かかる。直後に確認したいときは、レポート > リアルタイム。

## 追加するなら（実装はマーケとユーザーの確認後）

- `@next/third-parties/google` の `sendGAEvent("event", "synapse_created")` を、投稿成功時（`SmartInputPanel.tsx`）に1行。Xシェアのクリック（`SynapseSharePrompt.tsx`、`UserProfilePage.tsx`）に `share_click` を1行ずつ。合計 10行程度、3ファイル。
- イベントがGA4に届いたら、管理 > イベント で `synapse_created` を「キーイベントとしてマーク」する（これで投稿数が集計・流入元別に見られる）。
